# Kaspi Trend AI

Streamlit-приложение для изучения поисковых трендов Казахстана и анализа истории из CSV.

**Google Trends — это поисковый интерес в Google, а не продажи, заказы или поисковая статистика Kaspi. Прямое подключение к данным Kaspi отсутствует.**

## Возможности

- Автоматическое получение публичной RSS-ленты Google Trends с фиксированным регионом Казахстан (`geo=KZ`), без API-ключа.
- Таблица запросов с исходной оценкой поискового объёма, датой публикации и ссылкой на Google Trends по запросу и региону.
- Поиск по тексту, минимальная оценка объёма, включение записей без оценки, фильтр по дате публикации и сортировка. Выгрузка отфильтрованных результатов в CSV с указанием источника и типа данных.
- Существующий анализ пользовательского CSV: выбор категории, график динамики, средний интерес по месяцам, изменение между последними двумя доступными месячными средними, исторический месяц пика и скачивание обработанных данных.

## Запуск

Рекомендуется Python 3.12 (также поддерживается Python 3.11).

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows активация окружения: `.venv\Scripts\activate`.

Приложение откроется по адресу `http://localhost:8501`. Для получения RSS серверу нужен исходящий HTTPS-доступ к `trends.google.com`. Анализ CSV работает без доступа к Google.

## Поисковые тренды: источник и ограничения

Источник: [Google Trends RSS для Казахстана](https://trends.google.com/trending/rss?geo=KZ). Регион всегда `KZ`; приложение не подменяет недоступную ленту данными другой страны. [Официальная справка об экспорте Trending now и RSS](https://support.google.com/trends/answer/3076011?hl=en), [описание данных Google Trends](https://support.google.com/trends/answer/4365533?hl=en).

Первая загрузка выполняется при открытии приложения. Пока страница открыта, блок трендов обновляется каждые 15 минут. Серверный кэш разделяется между сессиями и действует 15 минут; кнопка «Обновить тренды» сбрасывает его и запрашивает источник заново. Ошибки также кешируются, чтобы изменение фильтров не создавало повторных запросов к недоступному источнику.

RSS может содержать новости и другие нетоварные темы. Это доступная лента Google, а не полный список всех запросов Казахстана и не рейтинг товаров Kaspi. Приложение не рассчитывает продажи, покупательскую конверсию или прогноз выручки на основании этой ленты.

- `approx_traffic` показывается как есть: например, `1K+` или `1,000+`. Для фильтрации и сортировки используется числовая нижняя граница. Это приблизительный поисковый объём, не индекс 0–100. Суммировать его как продажи нельзя.
- Отсутствующая оценка не заменяется нулём. Такие запросы можно включить отдельно, в том числе при заданном минимальном объёме.
- Фильтр даты относится к времени публикации записи в RSS, а не к периоду измерения объёма. Записи без даты показываются только без ограничения по времени. Время в таблице и статусе указано для `Asia/Almaty`.
- RSS не предоставляет здесь проверенные товарные категории, процент роста, сезонность или статистику Kaspi. Эти значения не придумываются.
- Google может вернуть пустую ленту, ошибку или ограничить доступ. При ошибке показывается последний успешный снимок текущей сессии с явным предупреждением и временем загрузки. Без такого снимка таблица пуста. Снимок не сохраняется между перезапусками сервера; демонстрационные данные не подставляются.

Запрос ограничен таймаутами подключения/чтения и размером ответа 2 MiB. Неожиданные редиректы, HTML и некорректный XML обрабатываются как недоступность источника.

## CSV-анализ

Формат входного файла в UTF-8:

```csv
date,category,value
2024-01-01,Обогреватели,10
2024-02-01,Обогреватели,20
2025-01-01,Обогреватели,30
2025-02-01,Обогреватели,60
```

Для этого примера изменение составит `+100.0%`, а исторический средний максимум приходится на февраль. Некорректные даты, значения, бесконечности и пустые категории исключаются. Файл с отсутствующими столбцами или без пригодных строк показывает сообщение об ошибке, сохраняя доступ к поисковым трендам.

Единицы `value` определяются вашим файлом. Для анализа сезонности желательно иметь минимум 2–3 года истории; приложение не подтверждает происхождение загруженных значений.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q app.py csv_analysis.py search_trends.py trends_ui.py
```

Тесты проверяют обработку RSS, ограничение размера и ошибок HTTP, фильтры, обновление и последний успешный снимок, а также работу интерфейса Streamlit и сохранение CSV-анализа. Сетевые ответы в тестах подменены: тесты не обращаются к Google и не доказывают текущую доступность RSS. GitHub Actions запускает эти проверки для pull request и push.

При подготовке этой версии публичная страница Google Trends для Казахстана была подтверждена через веб-инструмент. Live-загрузка RSS из среды разработки не подтверждена: `trends.google.com` отсутствует в её списке разрешённых сетевых адресов. Перед эксплуатацией проверьте источник в целевом окружении; интерфейс явно показывает ошибку, если данные получить нельзя.
